RELIST AGENT - EMAIL SETUP GUIDE
How to Configure Email for Daily Reports

OVERVIEW
========
Relist Agent sends a daily report of your relisted items via email.
You configure your own email account to receive these reports.

This keeps the load on your server minimal - users send from their own
email service (Gmail, Outlook, etc.).

SUPPORTED EMAIL SERVICES
========================

✓ Gmail (recommended)
  SMTP: smtp.gmail.com
  Port: 465 (TLS)
  Requires: App Password (not regular password)

✓ Outlook / Hotmail
  SMTP: smtp-mail.outlook.com
  Port: 587 (STARTTLS)
  Requires: App Password

✓ Yahoo Mail
  SMTP: smtp.mail.yahoo.com
  Port: 465 or 587
  Requires: App Password

✓ Domain Email (your own server)
  SMTP: mail.yourdomain.com
  Port: 465 or 587
  Requires: Email account password

✓ Other services
  SMTP: [service's SMTP server]
  Port: 465 (TLS) or 587 (STARTTLS)
  Requires: Email password or app password

GMAIL SETUP (RECOMMENDED)
=========================

1. Go to myaccount.google.com
2. Enable 2-Step Verification (if not already)
3. Generate "App Password":
   - Security > App passwords
   - Select "Mail" and "Windows Computer"
   - Copy the 16-character password
4. In Relist Agent Settings:
   - Email: your-email@gmail.com
   - Password: [16-char app password]
   - SMTP Server: smtp.gmail.com
   - SMTP Port: 465

OUTLOOK SETUP
=============

1. Go to account.microsoft.com
2. Enable Security Info (if needed)
3. Create App Password:
   - Security > Advanced security options
   - App passwords > Create a new app password
   - Copy the password
4. In Relist Agent Settings:
   - Email: your-email@outlook.com
   - Password: [app password]
   - SMTP Server: smtp-mail.outlook.com
   - SMTP Port: 587

DOMAIN EMAIL SETUP
==================

If you use your own domain email:

1. Ensure email account exists on your mail server
2. Get SMTP settings from your host:
   - SMTP Server: mail.yourdomain.com
   - SMTP Port: Usually 465 or 587
   - Security: TLS or STARTTLS
3. In Relist Agent Settings:
   - Email: your-email@yourdomain.com
   - Password: Email account password
   - SMTP Server: mail.yourdomain.com
   - SMTP Port: [as provided by host]

RELIST AGENT SETTINGS
=====================

In the app, click "Settings" and configure:

Email Configuration:
  ├─ Email Address: [your email]
  ├─ Email Password: [app password or account password]
  ├─ SMTP Server: [service SMTP]
  ├─ SMTP Port: [usually 465 or 587]
  └─ Report Recipient: [email to receive daily report]

IMPORTANT NOTES
===============

• App Password vs Account Password:
  Gmail, Outlook, Yahoo = use App Password (more secure)
  Other services = use account password
  Never share your email password!

• Port 465 = TLS (Implicit)
  Port 587 = STARTTLS (Explicit)
  Usually only one works per service

• Daily Report:
  Sent at your configured time
  Contains: Relisted items, zero-qty ended, failures
  Recipient: Email you specify in Settings

• Test Your Configuration:
  Click "Run Now" in the app
  You should receive an immediate test email

TROUBLESHOOTING
===============

Q: "Authentication failed" error?
A: 1. Verify email address is correct
   2. Check if you need App Password vs account password
   3. Try copying the password again (no extra spaces)
   4. Check SMTP server spelling
   5. Some services block "less secure apps" - check settings

Q: Email never arrives?
A: 1. Check spam/junk folder
   2. Verify recipient email in Settings
   3. Check Activity Log for errors
   4. Try "Run Now" to test
   5. Verify SMTP port is correct (465 vs 587)

Q: "Connection timeout" error?
A: 1. Check internet connection
   2. Verify SMTP server name (typos?)
   3. Check port number (465 vs 587)
   4. Some firewalls block SMTP - check with IT
   5. Try different port (if available)

Q: Want to use multiple email accounts?
A: Each user configures their own email
   No limit on how many users can use Relist Agent

SECURITY NOTES
==============

✓ Passwords stored locally in config.json (not sent to Relist Agent servers)
✓ Always use App Passwords if available (Gmail, Outlook, Yahoo)
✓ Never share your email password
✓ TLS/STARTTLS encrypts connections
✓ Delete old passwords if you change them

WHAT GETS SENT
==============

Each daily report email includes:

Subject: Relist Agent Report — [Date]

Body:
  Relisted (10):
    - [ID 123 -> ID 456] Item Title Here
    - [ID 789 -> ID 999] Another Item
    ...

  Zero-Quantity Ended (2):
    - [ID 111] Item with no quantity left
    ...

  Failures (0):
    (none)
