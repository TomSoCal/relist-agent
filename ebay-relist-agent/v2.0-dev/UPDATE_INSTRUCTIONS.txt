================================================================================
                    RELIST AGENT - UPDATE INSTRUCTIONS
================================================================================

STEP-BY-STEP GUIDE TO UPDATE YOUR APP
(Even if you've never done this before, just follow these steps exactly)

================================================================================
STEP 1: CLOSE THE CURRENT APP
================================================================================
1. Open the Relist Agent app on your desktop
2. Click "Exit" button to close it completely
3. Wait 5 seconds to make sure it's fully closed

================================================================================
STEP 2: BACKUP YOUR CURRENT VERSION (OPTIONAL BUT RECOMMENDED)
================================================================================
1. Find where your Relist Agent folder is installed on your computer
2. Right-click on the folder
3. Select "Send to" → "Compressed (zipped) folder"
4. Name it "Relist-Agent-BACKUP.zip"
5. Save it somewhere safe (your Desktop or Documents)

================================================================================
STEP 3: DOWNLOAD THE NEW VERSION
================================================================================
1. In the Relist Agent, click "Check for Update"
2. Click "Yes" when it asks "Download now?"
3. Wait for the download to complete (you'll see a confirmation message)
4. The file will be saved to your Downloads folder as:
   → Relist-Agent-[VERSION].zip

================================================================================
STEP 4: EXTRACT THE NEW VERSION
================================================================================
1. Open your Downloads folder (usually on your taskbar or desktop)
2. Find "Relist-Agent-[VERSION].zip"
3. Right-click on it
4. Select "Extract All..."
5. Click "Extract"
6. Wait for it to finish (you'll see a folder appear)

================================================================================
STEP 5: COPY YOUR SETTINGS (IMPORTANT!)
================================================================================
1. Find your OLD Relist Agent folder (where you currently have it installed)
2. Look for a file named "config.json" in that folder
3. Copy this file (Ctrl+C)
4. Go to the newly extracted "Relist-Agent-[VERSION]" folder
5. Paste the config.json file there (Ctrl+V)
   This keeps all your settings (API keys, email, etc.)

================================================================================
STEP 6: REPLACE THE OLD VERSION
================================================================================
1. Find your OLD Relist Agent folder
2. Move it to your Desktop (as a backup) or delete it
3. Move the NEW "Relist-Agent-[VERSION]" folder to where the old one was
4. Rename it back to just "Relist Agent Website" if you want (optional)

================================================================================
STEP 7: RUN THE NEW VERSION
================================================================================
1. Double-click on "Relist Agent.exe" in the new folder
   OR click the Relist Agent shortcut on your desktop
2. The app should start with all your old settings intact
3. Test it by checking the version number in Settings

================================================================================
STEP 8: VERIFY THE UPDATE WORKED
================================================================================
1. Open Relist Agent
2. Look in Settings section on the right side
3. Scroll down to the bottom
4. You should see the new version number
5. If the version number changed, the update was successful!

================================================================================
TROUBLESHOOTING
================================================================================

Q: The app won't start
A: Make sure you copied the config.json file from your old version

Q: I lost my settings
A: Restore from the backup you created in STEP 2, extract it, and copy
   the config.json file again

Q: I can't find my Downloads folder
A: Press Windows key + E to open File Explorer, look for "Downloads"
   on the left side menu

Q: Still having issues?
A: Contact support at: support@thetrashedpanda.com

================================================================================
That's it! You're done! The update is complete.
